# 新闻图片与文档附件

## 已实现

- 管理员在新闻编辑器中上传 JPG、PNG、WebP 图片，图片插入正文；每张最大 5 MB。
- 管理员可上传 DOC、DOCX、PPT、PPTX 附件；每个最大 50 MB。详情页提供下载链接，编辑时可移除或更换。
- 上传内容保存在应用的私有目录，数据库 `news_asset` 只保存元数据和新闻关联。未关联的文件只能由上传者预览；下线的新闻及其媒体不对公众开放。
- 未关联或从新闻移除的文件会在超过 7 天后，于后续上传时清理。新闻下线不会删除文件，以便重新发布。

## Docker 存储与迁移

生产 Compose 把 `news_media_data` 命名卷挂载到 app 容器内 `/var/lib/software-group/news-media`，通过 `NEWS_MEDIA_DIR` 指定目录。Nginx 不挂载此卷，访问必须经过 `/software-group/news/media/{id}` 的权限检查。

发布前先备份业务数据库和 `news_media_data` 卷，并执行 Flyway `V2__news_assets.sql`。`db-users-init` 在迁移后应用 `sg_app_svc` 的新表权限。随后构建并更新 app 容器。首次启用的新卷为空；旧新闻和旧附件数据不迁移、不删除。

**注意：** 新闻 HTML 正文仍保存在现有 `app_data` 卷中。完整恢复新闻需要同时恢复业务数据库、`app_data` 和 `news_media_data`。不要使用 `docker compose down -v`，该命令会删除命名卷。

## 本地验证

`mvn -o -f pom-war.xml -Dtest=NewsMediaServletIT test` 覆盖图片及 Word/PPT 上传、新闻发布、附件替换、下载、下线后的禁止访问。`docker compose config --no-interpolate --quiet` 验证 Compose 文件结构。已有本地预览进程必须重新加载新版 WAR 才能在浏览器看到新功能；重新加载时需保留 `.local-preview-data` 数据目录。

本次浏览器预览使用 `http://127.0.0.1:18082/software-group/`，数据库位于 `.local-preview-data/news-media-preview-db.mv.db`；新闻正文位于 `.local-preview-data/localstorage`，媒体位于 `.local-preview-data/news-media`。此预览是嵌入式 Tomcat/H2，和原有 18080/18081 预览及生产 Docker 数据相互隔离。
