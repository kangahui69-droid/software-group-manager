# 3.8 ai-service 手动验证步骤

> 本文档使用 PowerShell 命令

## 一、环境准备

### 1.1 启动基础设施服务

```powershell
cd E:/java/software_group_AI

# 启动 MySQL、Redis、Nacos、Sentinel、MinIO
docker-compose up -d mysql redis nacos sentinel minio

# 等待服务健康（约30秒）
docker ps --format "table {{.Names}}	{{.Status}}"
```

### 1.2 验证基础设施

| 服务 | 地址 | 验证命令 |
|------|------|----------|
| MySQL | localhost:3307 | `docker exec sg_mysql mysql -uroot -proot123 -e "SELECT 1"` |
| Redis | localhost:6379 | `docker exec sg_redis redis-cli -a redis123 ping` |
| Nacos | localhost:8848 | 浏览器访问 http://localhost:8848/nacos （账号 nacos/nacos） |
| Sentinel | localhost:8858 | 浏览器访问 http://localhost:8858 （账号 sentinel/sentinel） |
| MinIO | localhost:9000 | 浏览器访问 http://localhost:9001 （账号 minioadmin/minioadmin123） |

### 1.3 编译 ai-service

```powershell
cd E:/java/software_group_AI/ai-service

# 编译打包
mvn clean package -DskipTests

# 确认 JAR 文件生成
Get-ChildItem target/*.jar
```

## 二、启动 ai-service

### 2.1 方式一：直接运行 JAR

```powershell
cd E:/java/software_group_AI/ai-service

# 设置环境变量（PowerShell 语法）
$env:NACOS_HOST="localhost"
$env:NACOS_PORT="8848"
$env:NACOS_NAMESPACE="public"

# 启动服务（默认端口 8094）
java -jar target/ai-service-1.0.0.jar
```

### 2.2 方式二：Docker 运行

```powershell
# 构建镜像
docker build -t ai-service:1.0.0 .

# 运行容器
docker run -d `
  --name sg_ai_service `
  -p 8094:8094 `
  -e NACOS_HOST=nacos `
  -e NACOS_PORT=8848 `
  --network software-group-net `
  ai-service:1.0.0
```

### 2.3 验证服务启动

```powershell
# 检查服务健康状态
Invoke-RestMethod http://localhost:8094/actuator/health

# 查看日志
docker logs sg_ai_service --tail 50
```

## 三、API 接口验证

### 3.1 服务注册验证

**Nacos 控制台验证**
- 浏览器访问 http://localhost:8848/nacos
- 登录后进入「服务管理」→「服务列表」
- 确认 `ai-service` 已注册，所在分组为 `DEFAULT_GROUP`

```powershell
# 或者用命令验证
Invoke-RestMethod "http://localhost:8848/nacos/v1/ns/instance/list?serviceName=ai-service"
```

### 3.2 Feign 客户端验证

**验证 Feign 调用用户服务**

```powershell
# 模拟用户服务响应（先启动 user-service）
# 然后验证 AI 服务能否通过 Feign 获取用户信息

$body = @{
    message = "查看我的信息"
    sessionId = "test-session-001"
    userId = 1
} | ConvertTo-Json

Invoke-RestMethod -Uri "http://localhost:8094/api/ai/chat" `
    -Method Post `
    -ContentType "application/json" `
    -Body $body
```

预期响应：
```json
{
  "code": 0,
  "message": "ok",
  "data": "AI回复: ..."
}
```

## 五、常见问题排查

### 5.1 服务无法注册到 Nacos

```powershell
# 检查 Nacos 是否正常运行
docker ps sg_nacos

# 检查网络连接
docker exec sg_ai_service ping nacos

# 查看注册日志
docker logs sg_ai_service 2>&1 | Select-String "nacos"
```

### 5.2 Feign 调用失败

```powershell
# 检查目标服务是否已注册
Invoke-RestMethod "http://localhost:8848/nacos/v1/ns/instance/list?serviceName=user-service"

# 检查 Feign 超时配置
docker exec sg_ai_service find /app/config/ -name "*feign*"

# 查看详细日志
docker logs sg_ai_service --tail 100 | Select-String "feign"
```

### 5.3 数据库连接失败

```powershell
# 检查 MySQL 是否就绪
docker exec sg_mysql mysql -uroot -proot123 -e "SHOW DATABASES"

# 检查 AI 服务数据库配置
docker exec sg_ai_service env | Select-String "mysql"

# 查看连接错误日志
docker logs sg_ai_service --tail 50 | Select-String "connection","mysql"
```
